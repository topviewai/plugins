# Install Topview in Cursor

Install `topview-browser` from the approved Cursor Marketplace entry named
**Topview**, complete MCP OAuth in Cursor Settings, restart when requested, and
begin in a new Agent task. No companion VSIX or IDE-only side-panel extension is
required. Cursor's built-in Browser should open the returned Canvas URL inline;
opening the Browser remains subject to Cursor's user/admin approval controls.

Source: https://github.com/topviewai/plugins
